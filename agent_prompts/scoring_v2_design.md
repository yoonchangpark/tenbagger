# 스코어링 v2 설계 — "발굴 점수(Discovery Score)"

> 전제: `scoring_postmortem.md`. 현재 quality 점수(=컴파운더 스크리너)는 **보존**하고,
> 텐배거 발굴용 **별도 점수**를 신설해 같은 백테스트 하니스로 검증한다.
> 기존 등급/공식은 건드리지 않는다 (v1 API 불변 원칙).

## 0. 설계 원칙
1. **별도 점수**: `discovery_score`(0~10)를 추가. 기존 `total_score`/`grade`와 병렬 저장·비교. 덮어쓰지 않음.
2. **검증 우선**: 구현 → 5년·여러 base_year 백필 → 정답지(실제 승자) 대비 랭크 상관 개선 확인 → 그 다음에야 노출.
3. **점-인-타임 데이터만**: 백테스트 시점에 잡히는 재무로만 1단계 구성. 가격/주식수 필요한 팩터는 2단계.

## 1. 점-인-타임 가용 데이터 (확인됨)
`fetch_yearly_financials()` 연도별 제공:
`revenue, operating_profit, net_income, total_assets, total_equity, total_debt, cash, current_assets, current_liab, cfo, capex, fcf`
**미제공**: 주식수, 시가총액, EPS, DPS, 주가(단 `run_backtest`가 `price_base`는 별도 조회).

## 2. 발굴 점수 — 1단계 팩터 (재무만, 즉시 검증 가능)

핵심 철학: **과거 정점이 아니라 미래 인플렉션 셋업을 보상한다.** 현재 공식이 보상하는 것을 상당 부분 *뒤집는다*.

| 팩터 | 신호 | 논리 | 현재 공식과의 관계 |
|------|------|------|------------------|
| **A. 회복 여력 (트로프)** | 현재 영업이익률 ≪ 자기 과거 peak, 단 매출 유지·자본 양(+) | 눌린 실적 = 회복 업사이드. 반도체 2016 바닥 패턴 | growth/cashflow 점수를 **역전** |
| **B. 실적 인플렉션** | 최근연도 영업이익/순이익이 직전 저점 대비 **턴업** | 바닥 찍고 돌아서는 초입 | 신규 |
| **C. 재투자 런웨이** | capex/매출 높음 + 총자산 성장 | 캐파 선투자 = 미래 성장 (양극재·반도체) | FCF마진 보상을 **역전** (고capex는 FCF 깎임) |
| **D. 소형주 프록시** | 작은 total_equity/revenue | 10배 여력 (작은 베이스). *진짜 시총은 2단계* | 신규 |
| **E. 생존 가드레일** | 자본>0, 부채비율 과도하지 않음, 유동성 확보 | "싼 바닥"과 "파산 직전" 구분 (낙하하는 칼 회피) | 신규 (필수) |

**안티-피크 페널티**: 매출/마진/이익이 자기 사상 최고치 근처면 감점 (평균회귀 위험).

점수 합성(초안): `discovery = 0.30·A + 0.20·B + 0.20·C + 0.15·D + 0.15·E_pass − peak_penalty`
(가중치는 검증 후 튜닝. E는 게이트/페널티로도 가능.)

## 3. 2단계 팩터 (가격·주식수 필요 — 데이터 파이프라인 추가 후)
| 팩터 | 데이터 | 비고 |
|------|--------|------|
| **밸류에이션** PBR/PER/PSR | base_year 주가 × 시점 주식수 | pykrx `get_market_cap`로 상장주식수·시총 시점 조회 추가 필요 |
| **진짜 사이즈** 시총 버킷 | 동상 | 소형주 틸트 정밀화 |
| **주식수 희석** | 시점별 주식수 추세 | 유증·CB로 희석되면 감점 (한국 소형주 함정) |

> 2단계는 `run_backtest`에 시점 주식수 조회를 추가해야 하며, Railway에서 외부호출 안정성 확인 필요(price는 99% 성공 확인됨).

## 4. ⚠️ 생존편향 — 반드시 통제
백필 유니버스는 **현재 상장 종목(scores 테이블)**이라 **상폐 종목이 빠져 있다.**
- "바닥/트로프 매수" 팩터(A·B)는 이 편향에 **가장 취약**: 2016년 바닥이던 종목 중 많은 수가 상폐됐고, 살아남은 것만 데이터에 있어 **트로프 전략이 실제보다 좋아 보인다.**
- 통제책:
  1. base_year 유니버스를 "현재 상장"이 아니라 **그 시점 상장 종목**으로 구성 (가능하면 상폐 포함 리스트 확보).
  2. 불가 시, 결과에 "상폐 제외 표본 → 트로프 팩터 낙관 편향" 캐넛 명시(이미 backfill 메타에 유사 문구 있음).
  3. E(생존 가드레일)를 강하게 걸어 *백테스트에서* 회피되는지 확인 — 가드레일이 작동하면 편향 일부 상쇄.

## 5. 검증 프로토콜
1. `calculate_discovery_score(historical_fins)` 구현 (scoring.py 또는 `discovery.py`).
2. `run_backtest`에서 discovery_score도 계산, `backfill_results`에 컬럼 추가 저장.
3. **5년 백필 × base_year 2014~2020** 실행 (코호트 6~7개).
4. 성공 기준(정직하게, 10배 적중이 아니라 랭크 개선):
   - **Spearman 순위상관**(discovery_score vs return_pct) > 현재 total_score의 상관.
   - **상위 10% 발굴점수 종목의 포워드 중간 수익률** > 현재 TENBAGGER 중간 수익률(−14%) 및 시장 중간값.
   - 정답지(한미반도체·SK하이닉스·알테오젠 등)가 현재 AVOID에서 **상위 분위로 이동**하는지 확인.
5. 5년에서 효과 확인 → 10년(2016)으로 재확인 → CHANGELOG 기록 후 반영 검토.

## 6. 현실적 기대치 (과약속 금지)
- 10배 종목 base rate는 극히 낮다. 목표는 "10배를 정확히 콜"이 아니라 **랭크 상관과 상위분위 포워드 수익률을 시장 위로** 끌어올리는 것.
- 트로프/딥밸류 팩터는 변동성·드로다운이 크다(가치 함정·상폐 위험). 컴파운더(quality) 점수와 **병행 제시**가 합리적: "안정 복리(COMPOUNDER)" vs "고위험 발굴(Discovery)" 두 트랙.
