# 제품 방향 — 찾는다 → 확인한다 → 그려 본다

**목적**: 텐배거 헌터의 모든 기능이 한 방향(가치투자 관점의 장기 텐배거 발굴)을 보게 한다.
고객이 한 종목을 두고 "왜 후보인가 → 근거는 무엇인가 → 샀을 때 내 돈은 어떻게 되나"를 위에서 아래로 읽게 만든다.

**언제 쓰나**: "이 기능 넣을까?", "화면 순서 바꾸자", "텐배거 후보 어떻게 뽑아?", "시뮬레이션 숫자 이상해",
"이번 분기 후보들 어떻게 됐어?". 기능을 추가·삭제·재배치하기 전에 항상 먼저 읽는다.

**출처**: 2026-11-24 오너 인터뷰 (원문: `/mnt/project-files/ops-interview/system-improvement.md`).
전후 비교: https://claude.ai/artifact/Vkf4kM855xPFRzAGBWimyv

## 고객 가치 (오너 정의)
1. **찾는다** — 텐배거 후보. 박경철 "W를 찾아서": 시대의 흐름을 먼저 알아보고 올라탄다.
2. **확인한다** — DART만이 아니라 산업 성장·독점·재무 등 여러 근거로.
3. **그려 본다** — 이 종목을 샀을 때 장기적으로 내 자금이 어떻게 될지 시나리오로.
계좌 장기 관리는 중심이 아니다. 보유 종목은 시뮬레이션 입력으로만 쓴다.

## 단계
1. **INTERVIEW** — 요청이 세 단계 중 어디에 속하는지 정한다. 어디에도 안 들어가면 "흐름 안 재료로 바꿀 수 있나"를 먼저 묻고, 안 되면 화면에서 숨긴다(코드는 둔다).
2. **MANUAL** — 아래 판단 규칙.
3. **TOOLBOX** — `files/INDEX.md`.
4. **EXECUTE** — 화면 변경은 전후 비교 HTML을 먼저 오너에게 보인다. v1 API 불변.
5. **VERIFY** — `proof.md`.

## 판단 규칙

### 찾는다 (후보 선정)
- 순서: **시대 흐름(산업 테마)에서 수혜 기업을 모은다 → 재무 최소선을 통과한 회사만 남긴다 → 5고리 단계순으로 세운다.**
- 전 종목 재무 점수로 바로 후보를 뽑지 않는다. 10년 백테스트에서 그 방식의 TENBAGGER 등급은 중간 수익률 −14.1%, 실제 10배 종목 15개 중 13개를 놓쳤다.
- 테마는 내러티브다(숫자로 자동 추출하지 않는다). **AI가 초안을 쓰고 오너가 넣고 뺀다.**
- 테마 초안은 버핏·멍거 필터 네 개를 모두 채워야 올린다:
  1. 능력 범위 — 흐름을 한 문장으로 설명할 수 있나
  2. 누가 돈을 버나 — 수혜자 중 가격 결정력·진입장벽을 가진 쪽 (포드보다 록펠러)
  3. 뒤집어 보기 — 이 내러티브가 틀린다면 어떻게 틀리나, 그 신호는 무엇인가
  4. 안전마진 — 이미 가격에 반영됐나
- 화면 라벨은 "⭐ 텐배거 후보"가 아니라 "5고리 중 N고리 진입". API의 `grade` 값은 바꾸지 않는다.

### 확인한다 (근거)
- 뼈대는 내러티브 5고리: 수요 폭발 → 독자성 → 진입장벽 → **공급 부족**(화면 명칭. 주식 수급과 헷갈리지 않게) → 마진 상승.
- 모든 주장에 출처(공시·기사 링크)를 단다. 없으면 "미확인".
- 뉴스는 긍정·부정 점수가 아니라 5고리 근거로 붙인다 (예: 수주 급증 기사 → 수요 폭발).
- 실적 서프라이즈는 마진 상승 고리의 근거로 쓴다.
- 주식 수급은 판단 근거가 아니라 확인 신호: 며칠 순매수 대신 1년 누적 기관·외국인 지분과 주가 추세로 "아직 덜 알려짐 / 가격에 반영 중"을 표시한다 (백테스트상 모멘텀은 발굴엔 실패, 확인 필터로는 유효).
- 기존 재무 점수는 "재무 체력"(망하지 않을 회사인가)으로 남긴다.
- AI 정성 분석·투자위원회는 자유 서술이 아니라 5고리 질문에 하나씩 답한다.

### 그려 본다 (시나리오)
- 약세·기본·강세의 가정 성장률 = **이 회사의 실제 과거 실적 + 같은 5고리 단계였던 과거 종목들의 실제 결과 범위.** 화면에 출처를 표시한다.
- 등급별 고정 기대수익(예: TENBAGGER 연 12%)은 쓰지 않는다.
- 고객이 슬라이더로 조정하는 기능은 유지한다. MDD·배당 재투자를 함께 보여 준다.

### 기록과 공개
- 오너가 후보를 승인하는 날 **스냅샷을 고정**한다: 날짜, 내러티브, 5고리 판정과 출처, 주가, 약세·기본·강세 시나리오. 이후 수정 금지. 바꾸려면 새 버전으로 남긴다.
- 같은 스냅샷을 Notion **"텐배거 검증 일지"** 데이터베이스(오너 Notion의 Tebagger 페이지 아래)에 한 행으로 남긴다. 승인 후 행 내용은 고치지 않고, 바꿀 때는 `버전`을 올린 새 행을 추가한다.
- 스냅샷 카드뉴스는 **검증 일지** 형식이다 (오너 2026-11-24): "이 날 시스템이 이렇게 판단했다 → 분기마다 맞았나". 종목명은 나오지만 매수 권유는 없고, 틀린 것도 그대로 공개한다. 9/21 결정("카드뉴스는 종목 분석이 아니라 만드는 과정")의 연장으로, 종목 분석 카드는 여전히 내지 않는다. 절차는 `ops/cardnews/`, 발행은 `ops/threads/` 접점(`queue.add`)으로만.
- 화면·글의 표현은 "투자 조언"이 아니라 "근거와 시나리오". 유료 구독자에게 특정 종목 매수를 권하는 형태는 유사투자자문업 신고 대상일 수 있다 — 신고 필요 여부를 확인하기 전까지 매수 권유 문구를 쓰지 않는다.

## 완료 기준
종목 화면을 위에서 아래로 읽으면 찾는다 → 확인한다 → 그려 본다 순서이고, 화면의 모든 주장에 출처나 "미확인"이 붙어 있으며,
승인된 후보마다 수정되지 않은 스냅샷이 있다.

## 알려진 차이 (2026-11-24 main 기준)
- 종목 화면이 등급 → 수급 → 서프라이즈 → 뉴스 감성 → 차트 → 시뮬레이터 순. 흐름과 다르다.
- 5고리 체크리스트(`/api/v2/company/{ticker}/thesis-checklist`)는 API만 있고 화면에 없다.
- 시뮬레이터가 `_GRADE_CAGR`(등급별 고정 기대수익)을 쓴다.
- 테마 목록·스냅샷 저장소·Notion 기록이 없다.
- 첫 화면 문구 "저평가 성장주 발굴", "텐배거(10배) 달성"이 백테스트와 맞지 않는다.
- 유사투자자문업 신고 필요 여부 미확인.
