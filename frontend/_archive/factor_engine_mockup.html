요소 발굴 엔진
N년 전 예측 → 검증 → 개선 루프

재무 하나의 공식이 아니라, 여러 요소(재무·산업·내러티브·거시)를 후보로 던지고, 과거에 실제로 예측력이 있었는지 측정하고, 틀린 이유를 분석해 요소를 갈아끼우며, "진짜 맞히는 요소"만 살아남게 하는 자기개선 엔진. 핵심 규율은 과적합을 막는 walk-forward 검증.

1 자기개선 루프

회장님이 제안하신 "예측 → 검증 → 실패분석 → 수정 → 재검증" 그대로
① 예측
N년 전 시점, 요소 조합으로 등급 산출
→
② 검증
실제 이후 수익률과 대조 (IC·적중률)
→
③ 실패분석
틀린 종목의 빠진 요소 진단
→
④ 요소수정
요소 추가/가중치 조정
→
⑤ 재검증
건드리지 않은 기간으로 out-of-sample 확인
↻ ⑤가 통과하면 채택, 실패하면 ③으로 — 정확도가 오를 때까지 반복

3 요소 예측력 리더보드 (IC)

IC = 요소값과 이후 2년 수익률의 상관(−1~+1). 높을수록 예측력. ★in-sample만 높고 out이 0이면 과적합
요소IC (in-sample)IC (out-of-sample)안정성판정
검색량 가속도(저점)+0.31+0.27높음✓ 채택
매출 3년 CAGR+0.24+0.21높음✓ 채택
시장 독과점 지위+0.19+0.18높음✓ 채택
특정 분기 깜짝실적 패턴+0.42−0.03낮음✗ 과적합 탈락
부채비율+0.05+0.04—✗ 무의미 탈락
⚠ 4번째 줄을 보세요. in-sample IC가 +0.42로 가장 높지만, 건드리지 않은 기간에선 −0.03 — 즉 과거에 우연히 맞은 것입니다. IC만 보고 채택했다면 미래엔 무너졌을 요소. 이걸 걸러내는 게 walk-forward의 존재 이유입니다.

6 실패 분석 — "왜 틀렸나" 자동 진단 (예시)

종목 (2019 예측)A사 — WATCHLIST로 과소평가
실제 결과2년 +210% (텐배거급)

놓친 신호산업 전환점(전기차 침투율 급변) + 검색량 저점 가속
엔진 제안→ '산업 침투율 변화' 요소 후보 추가, 다음 루프에서 검증

실패 패턴이 쌓이면 "재무만으론 못 잡는 유형"이 드러나고, 그게 새 요소 후보가 됩니다 — 회장님 통찰 그대로.

7 정직성 가드레일

이 엔진은 잘못 쓰면 "과거에만 완벽한 거짓말 기계"가 됩니다. 다음을 강제합니다.
⚠ 반드시 지키는 규칙
  • out-of-sample만 신뢰: 학습 구간 성적은 절대 자랑하지 않음. 검증 구간 성적만 페이지·의사결정에 사용.
  • 다중검정 보정: 요소를 많이 던질수록 우연 발견이 늘어남 → IC 임계값을 표본·요소 수에 맞춰 상향.
  • 최소 표본: 텐배거는 희귀 → 타깃을 '시장 +50% 초과'로 넓혀 표본 확보. 표본 부족 요소는 '미검증' 보류.
  • 점-인-타임 고정: 모든 요소는 그 시점에 실제로 알 수 있던 데이터만. 미래참조 1건이라도 섞이면 전체 무효.
