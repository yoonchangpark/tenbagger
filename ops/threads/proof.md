# Threads — Proof

| # | 체크 | 판정 방법 |
|---|------|----------|
| 1 | 글자수 | 본문 ≤ 480자 (`MAX_CHARS`, Threads 한도 500) |
| 2 | 코드 이름 노출 0건 | 본문에 `.py`, `_`가 들어간 식별자, 대문자 환경변수 패턴 없음 |
| 3 | 숫자 출처 | 본문의 모든 숫자가 출처 CHANGELOG 항목 텍스트에 존재 |
| 4 | 질문으로 끝남 | 마지막 줄이 `?`로 끝남 |
| 5 | 중복 아님 | `source_key`(`changelog:<버전>`)가 발행된 글 목록에 없음 |
| 6 | 이미지 준비 | `image_urls` 각각 HEAD 200 |
| 7 | 실제 게시 | 발행 응답의 게시물 ID가 있고, 오너가 계정에서 확인 |
