# 숏츠 — Proof

| # | 체크 | 판정 방법 |
|---|------|----------|
| 1 | 소재가 텐배거 소재 목록의 종목이다 | 영상 제목·대본의 종목명이 `tenbagger_history.json` 또는 `CANDIDATES`에 존재 |
| 2 | 동반 성장 조건 충족 | DART 최근 두 사업연도 매출·영업이익이 모두 증가 |
| 3 | 대본 평가 통과 | 로그의 `대본 평가 점수` ≥ 70 (`evaluator/alignment.py`) |
| 4 | 대본의 숫자가 원자료와 일치 | 대본에 나온 매출·이익·이익률 각각을 DART 값과 대조, 불일치 0건 |
| 5 | 설명란에 텐배거 링크 | 업로드된 영상 설명에 텐배거 URL 문자열 포함 |
| 6 | 영상이 공개돼 있다 | `https://youtu.be/<video_id>`가 열리고 `data/videos.json`에 기록 |
| 7 | 금지 쌍 미포함 | 한화오션·HD한국조선해양이 같은 회차에 함께 나오지 않음 |
| 8 | 세로 규격 | 렌더 결과 해상도 1080×1920 |
