# 스코어링 포스트모템 — "왜 우리 TENBAGGER는 10년간 마이너스였나"

> 작성: 2026-06 · 데이터 출처: `backfill_results` (base_year=2016, hold_years=10, 현재 종가 기준 ~9.5년 실측)
> 검증 하니스: `app/domain/backfill.py` → `run_backtest()` 점-인-타임 재구성

## 1. 관측된 사실

10년 백필(1000종목 유니버스) 등급별 포워드 수익률 **중간값**:

| 등급 | 표본(priced) | 10년 중간 수익률 |
|------|------|-----------------|
| TENBAGGER | 5 | **−14.1%** |
| COMPOUNDER | 11 | +20.4% |
| WATCHLIST | 119 | +5.1% |
| AVOID | 509 | −15.3% |

- TENBAGGER가 COMPOUNDER보다 **나쁨** (등급 사다리 역전).
- 우리가 2016년에 TENBAGGER로 찍은 5개: 비아트론 −68.5%, 코텍 −22.9%, 헥토이노베이션 −14.1%, 한국화장품제조 +33.3%, 휴젤 +130.6%. (휴젤 외 전멸, 10배는 0개)

## 2. 결정적 증거 — 진짜 텐배거를 전부 AVOID로 찍음

2016→현재 실제 최대 승자 15개와 **우리가 2016년에 매긴 등급/점수**:

| 종목 | 실제 수익률 | 우리 등급 | 우리 점수 |
|------|-----------|----------|----------|
| 한미반도체 | +8,233% | WATCHLIST | 6.48 |
| 알테오젠 | +7,433% | AVOID | 3.69 |
| SK하이닉스 | +5,880% | AVOID | 3.48 |
| 삼성전기 | +3,823% | AVOID | 2.75 |
| 이수페타시스 | +2,840% | AVOID | 2.29 |
| 티에스이 | +2,694% | AVOID | 2.20 |
| 삼양식품 | +2,640% | AVOID | 3.54 |
| 한화엔진 | +2,497% | AVOID | 1.69 |
| 제주반도체 | +2,288% | AVOID | 1.48 |

→ 현재 TENBAGGER 등급은 실제 텐배거와 **역상관**.

## 3. 원인 — 4대 구조적 맹점

### 3.1 경기민감 저점(트로프) 인식 부재 — 최대 맹점
승자 15개 중 8개가 반도체 체인. 2016년은 메모리 다운사이클 바닥이라 실적이 눌려 ROE·마진이 낮았고 → 공식이 AVOID로 분류. 이후 슈퍼사이클+AI로 폭등.
**공식은 실적 정점(고ROE·고마진)을 사고 바닥을 버린다 = 사이클의 정반대 끝을 고른다.**

### 3.2 무이익·미래성장 동력 무시
알테오젠(2016 적자 R&D 바이오), 삼양식품(불닭 수출 전), 포스코퓨처엠(양극재 진입 전)은 성장이 **미래**에 있었다. 100% 후행 재무 기반 공식은 구조적으로 못 잡는다.

### 3.3 밸류에이션 0% 반영
`calculate_tenbagger_score()`는 `per`·`pbr`을 인자로 받지만 **점수에 안 쓴다**(scoring.py:400, 440, 450~452). 눌린 실적 = 싼 PBR = 재평가 여력인데 가격을 무시 → "이미 비싸진 우량주"를 가격 불문하고 찍는다.

### 3.4 TENBAGGER 게이트(성장 8.0+)가 역효과
TENBAGGER는 총점 7.5 + **과거 성장 8.0+**를 추가 요구(config.py:64) → 가장 가파른 후행 성장(=평균회귀 위험 최대인 정점)을 콕 집어 산다. 그래서 포워드 성과가 COMPOUNDER < TENBAGGER로 역전.

## 4. 재구성된 결론

- 현재 공식은 **"검증된 우량주(컴파운더) 스크리너"**다 — COMPOUNDER 등급이 +20%로 실제 최고 성과였음. 이 부분은 보존 가치 있음.
- 그러나 **텐배거(10배) 발굴기는 아니다.** 10배는 *바닥·저평가·무이익·미관심* 종목에서 나오며 정반대 팩터가 필요하다.
- 후행 퀄리티/성장 팩터는 **반감기가 짧다** — 호라이즌이 길수록 평균회귀로 예측력이 뒤집힌다. 텐배거 헌터는 장기에 잘 맞아야 하므로 팩터 방향이 어긋나 있었다.

## 5. 호라이즌 전략 (검증 방법론)

| 호라이즌 | 역할 | base_year |
|---------|------|----------|
| 5년 | 검증 주력 (코호트 6~7개로 통계 확보) | 2014~2020 |
| 10년 | 사명 점검(헤드라인·정답지), 단일 코호트라 단정 금지 | 2016(+2014·2015) |

10년 단일 코호트는 거시 경로 1개에 의존 → 통계적으로 얇다. 팩터 방향성은 5년·여러 base_year로 검증하고, 10년은 최종 확인으로 둔다.
