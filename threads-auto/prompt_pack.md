# 텐배거 Threads 콘텐츠 프롬프트 팩

Notion "Claude로 콘텐츠 기획하기" 프롬프트의 `[ ]`를 **텐배거 헌터** 컨텍스트로
채운 버전이다. 인스타 릴스/카드뉴스 중심 원본을 **Threads(텍스트 우선)**에 맞게 조정했다.

- **자동 생성**: `content_generator.py`가 아래 #0 페르소나 + #2 형식을 코드로 구현한다.
- **수동 기획**: 아래 프롬프트를 Claude 대화창에 그대로 붙여 쓴다. 결과 본문을
  `python main.py --add "..."` 로 큐에 넣으면 스케줄러가 자동 발행한다.

---

## 0. 계정 기본 설정 (대화 맨 처음 1회)

```
지금부터 너는 내 Threads 콘텐츠 전략가이자 카피라이터야.

1. 주제: 한국 주식 장기투자, DART 재무데이터 기반 '텐배거(10배 성장주)' 발굴
2. 타겟: 개별 종목을 스스로 공부하려는 개인 장기투자자 (30~50대, 직장인 투자자)
3. 타겟의 대표 고민:
   - 좋은 종목을 어떻게 고르는지 기준이 없다
   - 재무제표를 봐도 뭐가 중요한지 모른다
   - 단타·테마주에 휘둘려 장기 수익을 못 낸다
4. 내가 제공하는 것: 재무 기반 스코어링 스크리너, 텐배거 후보 발굴, 백테스트
5. 톤: 솔직하고 데이터 근거 중심. 과장·훅베이트 없음
6. 피할 표현: 단정적 매수/매도 권유, 근거 없는 목표주가·수익률 단언, 공포·조급함 조장
7. 목표: 저장 · 팔로우 (조회수만 노린 자극적 주제 금지)

앞으로 콘텐츠를 제안할 때 조회수보다 내 전문성(재무 분석)으로 자연스럽게
연결되는 방향을 우선해줘. Threads는 텍스트 위주이니 500자 이내로 짧게.

이해했다면 이 계정의 핵심 포지셔닝을 한 문장으로 정리하고,
콘텐츠 기획 원칙 5가지를 알려줘.
```

## 1. 트렌드·소재 찾기

```
나는 재무 기반 텐배거 발굴 콘텐츠를 운영하는 크리에이터야.
타겟은 스스로 종목을 공부하려는 개인 장기투자자야.

한국 장기투자·성장주 테마에서 최근 화제인 흐름을 웹 검색으로 조사해줘.

1. 최근 관심이 큰 성장 테마 5개 (예: AI 전력, K-방산, 바이오 등)
2. 개인투자자가 반복해서 어려워하는 질문 5개
3. 이미 식상해진 콘텐츠
4. 아직 덜 다뤄진 새로운 각도 (재무지표 해석 등)
5. 내가 놓치고 있을 소재
6. 재무 스코어링/백테스트와 연결할 수 있는 소재 5개

각 소재는: 제목 / 봐야 하는 이유 / 첫 문장 후킹 / 핵심 3가지 / 추천 CTA.
저장·공유할 만큼 실용적인 것만.
```

---

## 2. Threads 게시물 형식 (핵심 · 생성기가 쓰는 형식)

```
아래 주제로 Threads 게시물 1개를 작성해줘.

주제: [종목 또는 테마 — 예: 한화에어로스페이스 K-방산 성장]

형식:
1) 첫 문장: 시선을 끄는 한 줄 (사실만)
2) 본문: 핵심 포인트 2~3개 — 매출/영업이익 추세, ROE, 부채비율 등 재무 근거 중심
3) 마무리: 저장을 유도하는 가벼운 한 줄
4) 해시태그 2~4개
5) 맨 끝 줄: ※ 투자 판단·손익은 본인 책임

전체 500자 이내. 인사말/서론 없이 본문부터. 특정 종목 매수/매도 단정 금지.
```

---

## 3. 오프닝 문장 10개

```
주제는 [주제]야. 타겟은 개인 장기투자자.
이 글을 본 뒤 [저장 / 팔로우]하게 만들고 싶어.

오프닝 한 줄 10개를 만들어줘. 각각 아래 감정 트리거를 하나씩 써줘.
호기심 / 공감 / 반박 / 실수 지적 / 숫자 충격 / 의외성 / 손해 회피 / 결과 제시 / 비교 / 질문

과장·거짓 없이 본문에서 실제 설명 가능한 문장만.
가장 반응 좋을 3개를 골라 이유도 알려줘.
```

---

## 4. 캡션·CTA

```
아래 내용으로 Threads 마무리 문장과 CTA를 만들어줘.

내용: [게시물 본문 붙여넣기]
목표: [저장 / 팔로우 / 프로필의 스크리너 링크 클릭]

- 저장 유도 CTA 3개
- 팔로우 유도 CTA 3개
- 스크리너로 자연스럽게 잇는 문장 3개
재촉·불안 조장 표현 없이. 각 한 줄.
```

## 5. 성과 분석 → 다음 개선

```
아래는 최근 Threads 게시물 성과야.
주제: [주제] / 조회: [ ] / 좋아요: [ ] / 댓글: [ ] / 저장: [ ] / 팔로우 증가: [ ]

잘된/부진한 이유를 분석해줘. 점검: 주제 적합성 / 첫 문장 힘 / 재무 근거 구체성 /
저장 가치 / CTA 자연스러움 / 스크리너 연결 / 길이.

분석 후: 새 오프닝 5개 / 더 구체적인 각도 3개 / 다음에 실험할 요소 / 유지·삭제할 부분.
```

## 운영 흐름 요약

```
#0 계정 설정 (1회)
  → #1 소재 발굴  →  #3 오프닝 선택  →  #2 본문 생성  →  #4 CTA
  → python main.py --add "완성 본문"   (또는 content_generator.py로 자동 생성)
  → 스케줄러가 07:30/12:30/18:30/21:00 자동 발행
  → #5 성과 분석 → 다음 콘텐츠 반영
```
