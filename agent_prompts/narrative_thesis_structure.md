## 0. 한 줄 요약

**산업 수요 폭발 → 기업의 독자성 → 쉽게 못 따라오는 진입장벽 → 수급 불균형 → 단가·마진 상승**

다섯 고리는 **시간 순서**다. 앞쪽 고리(수요·독자성)는 말로만 먼저 보이고, 뒤쪽 고리(수급·마진)는
나중에 재무제표에 숫자로 찍힌다. 그래서 이 구조는 "좋은 종목인가"와 함께
**"지금 이 이야기의 몇 번째 고리에 와 있나"**를 알려줘야 한다.
마진까지 이미 터진 종목은 증거는 확실하지만 늦었을 수 있고, 앞 고리만 보이는 종목은 이르지만 불확실하다.

## 1. 고리별 정의

각 고리는 **두 종류의 판정**을 가진다.
- **서술 판정(LLM)**: 리서치 근거를 읽고 판단. 근거(출처·날짜·인용)가 없으면 무조건 `미확인`.
- **숫자 확인(DART)**: 재무제표로 계산. 사람·LLM 판단이 끼지 않는다.

상태값은 셋: `확인` / `미확인`(근거 부족) / `반증`(근거가 반대를 가리킴).

### ① 산업 수요 폭발
| 구분 | 내용 |
|---|---|
| 질문 | 이 산업의 수요가 구조적으로(일시적 유행이 아니라) 몇 년간 늘어날 이유가 있나? |
| 서술 판정 | 수요 동인을 **이름 있는 사건·계약·정책**으로 1개 이상 제시. 예: "미국 송전망 교체 예산", "빅테크 데이터센터 증설 발표". 추상 요약("AI 성장")만 있으면 `미확인`. |
| 숫자 확인 | 매출 2년 CAGR ≥ 20% · 매출채권/매출이 악화되지 않음(밀어내기 매출 배제) |
| 반증 신호 | 매출 성장이 한 해뿐이고 재고·채권이 같이 불어남 |

### ② 기업의 독자성
| 구분 | 내용 |
|---|---|
| 질문 | 같은 산업 안에서 왜 이 회사가 수요를 가져가나? |
| 서술 판정 | 제품·고객·인증·지역 중 **경쟁사가 없는 것**을 구체적으로. 예: "북미 전력사 인증 보유 소수 업체". 주요 고객사명이나 공시된 계약을 근거로. |
| 숫자 확인 | 매출총이익률 ≥ 25%이고 하락하지 않음 (원가에 얹을 수 있는 몫) · 영업이익률 ≥ 5% (판관비를 치르고도 남음) |
| 반증 신호 | 매출은 늘지만 매출총이익률이 제자리·하락 = 누구나 파는 물건 |

### ③ 쉽게 못 따라오는 진입장벽
| 구분 | 내용 |
|---|---|
| 질문 | 경쟁사가 이 공백을 몇 년 안에 메울 수 있나? |
| 서술 판정 | 장벽의 **종류와 기간**을 명시: 특허 / 기술·공정 노하우 / 인증 취득 기간 / 증설 리드타임 / 규제 인허가. "기술력이 좋다"만 있으면 `미확인`. |
| 숫자 확인 | 매출총이익률이 **3년 연속** 유지 이상 (장벽이 없으면 경쟁 진입으로 마진이 먼저 깨진다) |
| 반증 신호 | 경쟁사 증설·신규 진입 공시, 마진 하락 반전 |
| 한계 | 특허 건수·R&D 비율은 DART 재무 API에 안정적으로 없다. 당장은 서술 판정에 의존. |

### ④ 수급 불균형
| 구분 | 내용 |
|---|---|
| 질문 | 만드는 것보다 사려는 게 많은 상태가 실제로 나타나나? |
| 서술 판정 | 수주잔고 증가, 납기 연장, 증설 발표 (사업보고서 본문·공시에서 인용) |
| 숫자 확인 | 매출 증가율 > 유형자산 증가율(설비보다 수요가 빠름) · 재고/매출 하락 **또는** 계약부채(선수금) 1.5배 이상 (수주생산 업체는 재고가 수주와 함께 늘어서) |
| 반증 신호 | 재고/매출 상승, 대규모 증설로 공급이 따라잡기 시작 |

### ⑤ 단가·마진 상승
| 구분 | 내용 |
|---|---|
| 질문 | 수급 불균형이 가격과 이익으로 옮겨가고 있나? |
| 서술 판정 | 판가 인상·가격 협상력 언급 (IR·사업보고서) |
| 숫자 확인 | **매출총이익률 확장(%p)** — 판가 상승을 가장 직접 보여줌 · 영업이익 증가율 > 매출 증가율(영업 레버리지) · 기존 `momentum_score` |
| 반증 신호 | 매출총이익률 정점 후 하락 |

### 가드레일 (고리와 별개, 항상 확인)
- 주식수 희석(유증·CB) 여부
- 밸류에이션: 이미 PER·PBR이 업종 대비 크게 높으면 "좋은 회사, 비싼 주식"으로 표시
- 부채비율·영업현금흐름 적자 지속 여부

## 2. 출력 형식 (종목 1개)

```json
{
  "ticker": "033100",
  "links": {
    "demand":    {"status": "확인", "evidence": [{"source": "...", "date": "2024-05", "quote": "..."}], "metrics": {"revenue_cagr_2y": 74.7}},
    "unique":    {"status": "확인", "evidence": [...], "metrics": {"gross_margin": 51.7}},
    "barrier":   {"status": "미확인", "evidence": [], "metrics": {"gross_margin_3y": [37.6, 49.6, 51.7]}},
    "imbalance": {"status": "확인", "evidence": [...], "metrics": {"inventory_to_revenue": [29.9, 23.4, 16.8]}},
    "margin":    {"status": "확인", "evidence": [...], "metrics": {"gross_margin_delta_pp": 14.1, "momentum_score": null}}
  },
  "stage": "⑤ 마진 반영 완료 — 이야기 후반부",
  "guardrails": {"dilution": false, "valuation": "..."}
}
```

`stage`는 **확인된 고리 중 가장 뒤쪽 번호**로 정하되, ① 수요가 숫자로 확인되지 않으면 0이다. 뒤 고리가 확인됐는데 앞 고리가 `반증`이면
(예: 마진은 올랐는데 수요 근거가 없음) 일회성 가능성으로 표시한다.

## 3. 적용 예시 — 제룡전기(033100), DART 별도재무제표 2022→2024

| 고리 | 숫자 | 판정 |
|---|---|---|
| ① 수요 | 매출 861억 → 1,839억 → 2,627억 (2년 CAGR 약 75%) | 숫자 확인 |
| ② 독자성 | 매출총이익률 37.6% → 49.6% → 51.7% | 숫자 확인 |
| ③ 장벽 | 매출총이익률 3년 연속 상승 | 숫자 확인, 장벽 종류는 서술 근거 필요 |
| ④ 수급 | 재고/매출 29.9% → 23.4% → 16.8%, 유형자산은 178억 → 198억으로 거의 그대로 | 숫자 확인 — 설비 증설 없이 매출 3배 |
| ⑤ 마진 | 매출총이익률 +14.1%p, 영업이익률 18.6% → 37.2% | 숫자 확인 |

→ `stage`: ⑤. 다섯 고리가 모두 숫자로 찍힌 **후반부** 종목이다. 증거는 가장 확실하지만,
같은 틀로 2022년에 봤다면 ①②만 보이는 단계였을 것이다. 이 구조의 쓸모는 그 **초반부 종목**을 찾는 데 있다.

## 4. 이 구조를 어디에 쓰나 (제안)

1. **라이브 후보 평가** — 지금 시점 종목에 적용. 결과를 아직 모르므로 사후편향이 없다. 먼저 여기부터.
2. **숏츠 후보(`v2_shorts_feed.py` CANDIDATES)** — 이미 있는 `narrative`/`thesis_type`/`facts`를 이 다섯 고리로 채워 일관성 확보.
3. **과거 검증** — ④⑤ 숫자 확인만 점-인-타임으로 백테스트 가능. ①②③ 서술 판정의 과거 검증은
   LLM이 결과를 이미 알고 있어 오염된다(숏츠 스레드에서 정리한 사후편향 문제). 서술 판정은
   **오늘부터 기록해 두고 앞으로의 실제 수익률로 검증**하는 게 정직한 방법이다.

## 5. 펀더멘털 강화 — 필요한 데이터

기존 `fetch_yearly_financials()`에는 **매출총이익·재고자산·매출채권·계약부채**가 없다. 그 결과가 v1
`/api/company` 응답에 그대로 실리므로 v1은 건드리지 않고 **v2 전용 추출**
(`backend/app/domain/thesis_checklist.py`의 `fetch_thesis_financials`)을 따로 만들었다.
사업보고서 1건에 당기·전기·전전기가 같이 들어 있어 **종목당 DART 호출 1~2회**로 3개년을 얻는다.

## 6. 아직 없는 것 (정직하게)
- 수주잔고: 사업보고서 **본문**에만 있고 재무 API에는 없다 → 공시 본문 추출이 필요.
- 특허·R&D: 재무 API에 안정적으로 없다 → 외부 소스(KIPRIS 등) 또는 서술 판정.
- 동종업계 비교(마진이 "업계 대비" 높은가): 업종 분류와 피어 그룹 정의가 먼저 필요.
- 리서치 근거 수집: aiva_server의 NotebookLM 딥리서치 단계가 현재 실패 중(숏츠 스레드 확인). 서술 판정의 근거 품질이 여기에 달려 있다.

## 7. 세부 체크리스트 (구현: `GET /api/v2/company/{ticker}/thesis-checklist`)

고리마다 서술 항목(근거 필수, 지금은 전부 `미확인`)과 숫자 항목을 둔다.
고리의 숫자 판정: 숫자 항목 전부 통과=`확인`, 전부 실패=`반증`, 그 외=`미확인`.

| 고리 | 서술 항목 (근거 필요) | 숫자 항목 (DART) |
|---|---|---|
| ① 수요 | 이름 있는 수요 동인 · 여러 해 이어질 구조적 이유 | 매출 2년 CAGR ≥ 20% · 매출채권/매출 +5%p 이내 |
| ② 독자성 | 경쟁사에 없는 것(제품·고객·인증·지역) | 매출총이익률 ≥ 25% · 매출총이익률 하락 안 함 · 영업이익률 ≥ 5% |
| ③ 장벽 | 장벽 종류 · 따라오는 데 걸리는 기간 · 경쟁 진입 공시 없음 | 매출총이익률 연간 하락폭 ≤ 2%p · 3년 모두 영업흑자 |
| ④ 수급 | 수주잔고·납기 연장 · 증설 계획과 완료 시점 | 매출 증가율 > 유형자산 증가율 · (재고/매출 하락 **또는** 계약부채 1.5배 이상) |
| ⑤ 마진 | 판가 인상·가격 협상력 언급 | 매출총이익률 +3%p 이상 · 영업이익 증가율 > 매출 증가율 · momentum_score ≥ 5 |

`stage` = 숫자로 확인된 가장 뒤 고리. 단 **① 수요가 확인되지 않으면 0**이다. 매출이 안 느는 회사의
마진 개선은 비용 절감이지 수급 불균형 이야기가 아니기 때문이다.

### 실데이터 점검에서 고친 것 (DART 사업보고서 원자료, 4건)

| 사례 | 첫 판정 | 문제 | 고친 규칙 |
|---|---|---|---|
| 이마트 2022→2024 | stage ② | 유통업은 매출총이익률 31%라도 영업이익률 0.2% — 독자성이 아님 | ②에 영업이익률 ≥ 5% 추가, stage는 ① 확인이 전제 |
| HD현대일렉트릭 2022→2024 | ④ 미확인 | 수주생산이라 수주가 쌓이면 재공품 재고가 늘어 재고 신호가 거꾸로 나옴. 계약부채는 3,053억 → 1조 519억 | ④ 재고 하락 **또는** 계약부채 1.5배 |

### 고친 뒤 결과

| 사례 | stage | 눈여겨볼 점 |
|---|---|---|
| 제룡전기 2022→2024 | ⑤ | 다섯 고리 전부 숫자 확인 |
| 제룡전기 2020→2022 | ⑤ | ③ 미확인(2021년 매출총이익률 19.8 → 15.6%로 꺾임), ④ 미확인(재고/매출 상승). 이 시점 이후에도 주가는 크게 올랐다 — ⑤가 "늦었다"를 뜻하지는 않는다 |
| HD현대일렉트릭 2020→2022 | 0 | 수요·마진은 숫자에 안 보였지만 **④는 확인**(계약부채 1,883억 → 3,053억). 선수금이 다른 숫자보다 먼저 움직인 사례 |
| HD현대일렉트릭 2022→2024 | ⑤ | 계약부채 3.4배 |
| 이마트 2022→2024 | 0 | ⑤ 반증(영업이익 감소, momentum 0) |

⚠️ 사례 4건으로 규칙을 고친 것이다. 과적합 위험이 있으므로 이 임계값들은 **확정이 아니라 출발점**이고,
④⑤ 숫자 항목은 점-인-타임 백테스트로 따로 검증해야 한다(§4-3).
